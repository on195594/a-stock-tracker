# 个股研究窗口

**Visitor mode: Operate.**

## Task and Context

用户已确认：本人、手机优先、收盘后快速核查；输入公司 → 成本确认 → 财报摘要与反证 → 判断与引用 → 按需单独确认价格参考 → 返回或退出；初筛为可选发现入口。产品范围和数据合同引用 README 与架构；本 brief 只维护这组页面的表达。

## Chosen Expression

用户选择“窗口索引”，与 DESIGN.md 的全局世界一致。来源/资料身份用矿蓝横带，日期和有效期分别标明；候选用完整名称、代码和细分隔线，不使用交易卡片或可操作信号。财报详情先读状态、资料日期、最强反证全文和前三条缺口，再读判断段落及引用。价格参考为独立浅底事实区，不调用模型。没有行情图像或图表槽位。

## Hierarchy

1. 壳层显示品牌、明确 demo 身份及账户入口。
2. 首页以“研究一家公司”为主、“从初筛找公司”为次、“独立价格参考（不调用模型）”为第三入口；`/analysis` 默认财报研究。最近摘要仅在首页，摘要卡显示财报状态、反证首句及资料日期，价格参考显示收盘、失效线、距离及有效期；过期隐藏价格，再提供详情动作。原 `/published` 发布入口已退役。
3. 财报详情按摘要 → 业务/财务/估值方法/改变判断的条件 → 可展开原文事实排序；每段列引用编号，URL 为纯文本。价格参考详情列程序事实、依据日期与有效期。
4. 登录、账户、空状态和读取失败沿用同一字体、颜色及动作规格，不显示未授权批次内容。

## States and Interaction

分别表达后台执行中、服务未连接/未配置、无可用研究结果、初筛部分完成可继续、无价格参考、旧规则未入选、资料缺口、财报复核失败、过期、读取失败。每个状态有明确原因或合法返回路径；读取失败允许重试，但不恢复旧工作台入口。过期仍可读历史非行动事实，主区域及展开依据都隐藏可行动条件。demo 仅使用现有合成数据。

私有页在读取后再次核验会话，退出或撤权后不写出私有内容；Web 不直接增加价格计算、采集、模型调用、交易操作或个人状态；新增网关只提交本人已确认的有界后台研究请求。48px 动作目标、语义标题和可读的展开名称支持键盘与触控。长公司名、长来源和多行反证必须换行，不横向溢出。

## Code-first Quality Bar

按服务端 HTML 与原生控件实现，不以概念图当完成页；颜色/字体角色用共用定义，真实状态和真实点击可测试。验证 360/390/430px 与桌面，检查日期、反证、按钮、展开依据以及退出后内容隔离；不允许隐藏到期价格的规则因布局变化失效。

## Direction contract

THESIS: 日期与观察窗口成为核查索引，拒绝把候选排成交易卡片或 KPI 仪表盘。

OWN-WORLD: 冷矿蓝整页底、深墨正文、矿蓝来源/日期横带、琥珀反证、浅底左标记价格区；细线分候选，无阴影。

STORY: 首页从三类研究入口或进行中/最近研究进入；结果页（`run.html`）先看执行状态、资料日期、最强反证与缺口（或初筛同业候选、价格纪律参考），再读分节判断、原文引用与可展开依据；没有资料不凑推荐。

FIRST VIEWPORT: 手机 20px 边距，顶部品牌与账户、30px 页面标题；首页首屏为三类研究入口及进行中/最近研究摘要，`run.html` 首屏为返回链接、执行/覆盖横带与主结果（财报摘要与反证、初筛每组前三候选或价格参考），底部展开依据。桌面限制 760px，不用卡片补满空白。

FORM: 有界日期索引，grounded 顺序第 3，seed `8db48fc6`；用户选择代码优先的“窗口索引”，不是 image-first comp。签名交互是可展开的核查依据与 AI 引用，到期只保留非行动依据。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, and DESIGN.md.

## Direction Provenance

本轮用户显式选择“窗口索引”；概念 seed 为 `8db48fc6`。跨域挑战带入：价格同尺度、完整解释不截断、固定状态颜色。采用这些纪律而不带入字体滑杆、媒体滚屏或不存在的核查地图。没有锁定 image-first comp；最终质量以代码、实际浏览器和当前安全测试为准。

## Web research extension

用户已明确要求纠正终端与网页割裂：首页优先“研究一家公司”，原生选择类型/输入代码，预算与模型报价横带，复选框明确确认后才提交。网页展示进度、缺口与覆盖，初筛先展示候选和研究动作，再展开完整排名与运行依据；候选可预填研究，最近请求只在首页重开。财报报告到价格参考是独立确认步骤。入口与结果使用同一窗口索引世界；无 CLI 用户步骤、无旧工作台、无自动调度。受理未知核对同一编号，不以新请求替代核对，不承诺提供方零费用；预算变化明确拒绝后保留输入、清除确认并重新报价。费用文案随模式变化，初筛/价格参考不调用模型。独立接收器保存凭据，Web 无行情/模型凭据。保留在途撤权、轮询 401 停止与到期隐藏反例。
