# 离线验证：冻结规则与证据

本页维护离线重放、前瞻账本合同及历史研究证据；与网页主流程分离。产品定位见 [README](../README.md)，在线数据与安全边界见 [架构](architecture.md)，生产操作见 [运维](operations.md)。


冻结的 `swing-observation-v1` 仍用于离线重放：收盘 > MA20 > MA60、20日相对沪深300涨幅差为正；区间下沿 = 20日最高 + 0.01、上沿 = 下沿 × 1.02；成交量条件为20日均量 × 1.5；上沿到10日最低价距离不超过 8%。`RULE` 与 `price_conditions()` 公式保持冻结。网页与批处理新输出使用独立规则身份，不混为同一策略版本。

`replay` 仅验证冻结的 `swing-observation-v1`，与 Web 和研究服务分离，不调用模型。`fetch` 需要环境变量 `TUSHARE_TOKEN`；每次真实拉取及续拉都须确认日期范围、请求预算与费用边界，以下示例不构成授权：

```bash
# 首次使用全新私有目录；日期固定后不可在同一目录更改范围
.venv/bin/python -m a_stock_tracker.replay fetch \
  --root /private/swing-replay --start 20231001 --end 20261012 --request-budget 900
# 只读取已完成缓存；输出须使用缓存目录之外的新文件名
.venv/bin/python -m a_stock_tracker.replay run \
  --root /private/swing-replay --horizon 60 --out /private/replay-result.json
```

- root 必须是绝对路径、0700 私有目录，拒绝符号链接、已有无关文件、`data/research` 或研究服务根目录及其内部目录。缓存和输出须留在 Git 忽略的私有路径，不挂载给 Web。
- 拉取交易日历、L/D/P 证券名单、沪深300日线、逐交易日全市场日线和每月范围内最后交易日的 PB/总市值快照（末月可能不足整月）。使用带哈希与来源时间的原子 JSON 缓存，不使用 pickle；已有缓存通过完整性校验后跳过。每次请求前等待至少 0.5 秒，每项失败最多尝试三次，所有尝试均计入本次硬预算；预算耗尽或失败返回非零，保留已完成文件，续拉须重新授权。
- 重放与在线评估调用同一个价格条件纯函数，保留 8% 距离上限；61 日完整性与价格连续性校验后，按每股 10 个交易日去重，观察后 5 日按失效、触发、跳过区间顺序判定。前瞻收益按 `pre_close` 链计算，输出通过率、随机基线、趋势/相对强弱组、观察组和触发组的收益、超额、20 日 MAE 与止损模拟。默认前瞻 60 日；短于 20 日仍预留 20 日用于 MAE/止损统计。
- 价格舍入以现有 `evaluate()` 的 Python `round` 为准（如 `11.25 × 1.02` 为 11.47），参考脚本 NumPy 舍入可能为 11.48；成交量阈值也保留在线规则的两位舍入。因此边界样本可能与历史 `full.json` 不同，不为追平历史数字修改规则。
- 历史输出标记 `methodology=historical-replay-v2`：按每次入场独立计算完整收益链，中间缺日、无效价格不补零，也不受入场前坏值污染；MAE/止损同样检查所需窗口。5 日结果复用前瞻的价格连续性检查，终局前缺日或除权基准断裂记 `data_gap`。JSON 用 `null` 表示不可得；既有报告保留原样，不冒充新口径结果。当前名称不能代替逐日 ST 名单，且没有 ROE、交易成本、T+1 和涨停成交约束，结果不作为收益证明。月末估值快照仅缓存，本阶段不重做参考脚本的替代策略、调参和价值池探索。

**前瞻验证（P3，冻结旧规则）**：使用独立的新账本目录，与历史 `fetch/run` 缓存不可混用。每次 `scan/settle/auto` 都是真实请求入口，即使部分数据可复用缓存，也须逐次确认范围、请求预算与费用边界。不调用模型、不接入 Web 或研究服务（支持独立无人值守周定时器，见 [运维](operations.md)）；晋升门槛未满足前不得进入首页，通过也只支持另行讨论，不自动发布。

```bash
# 用已收盘交易日替换 YYYYMMDD；当日扫描须上海时间18:00后
# 冷缓存通常66次请求；100为含失败尝试余量的显式上限，示例不是运行授权
.venv/bin/python -m a_stock_tracker.replay scan \
  --root /private/swing-forward --as-of YYYYMMDD --request-budget 100
# 另一次授权，只结算已满后续65个交易日（5日窗口+60日前瞻）的扫描
.venv/bin/python -m a_stock_tracker.replay settle \
  --root /private/swing-forward --request-budget 100
# 完全离线；输出到原账本之外的新文件
.venv/bin/python -m a_stock_tracker.replay report \
  --root /private/swing-forward --out /private/forward-report.json
# 无人值守：扫描最近已收盘交易日（若尚未扫描）、结算到期样本并输出不可变报告
# 单次总请求预算在各步骤间共享；报告目录须与账本根目录物理分离
.venv/bin/python -m a_stock_tracker.replay auto \
  --root /private/swing-forward --request-budget 100 \
  --report-dir /private/swing-forward-reports
```

- `scan` 获取截至 as_of 共61个交易日的全市场日线、沪深300、证券名单与日历；沿用主板、身份、ST/退、完整日线及价格连续性校验，调用冻结的 `price_conditions()`，观察按代码排序而非新增评分。当日所有有效股日按固定种子0与日期派生随机种子，最多抽500只作为基线，包含未满足观察条件的有效股票。历史补扫可留档；只有在 as_of 的下一交易日上海时间 09:15 集合竞价开始前完成并冻结的扫描才具前瞻资格。18:00 是当日资料可用性边界，不是前瞻资格边界；日历一次读取覆盖 as_of 后 32 个自然日，无下一交易日则拒绝，不追加请求预算。记录开始、完成时间和下一交易日截止时间，跨开盘完成的任务不得计入晋升。
- `settle` 不处理未到期扫描。每个观察保留5日结局 `triggered/invalidated_first/gap_above/expired/data_gap` 与触发日；观察日收盘及触发日收盘分别计算10/20/40/60日收益、相对沪深300超额、20日MAE和止损模拟；基线从扫描日收盘计算。双方收益都用 `pre_close` 链复权；止损按调整后低价跌破失效线、以开盘价与失效线较低者模拟，未触及则用20日收盘收益。MAE为不大于0的不利波动，数值越大越好。缺日、零量或无效价格保留日期并输出 `null`，不填零、不跨缺口接链；5日窗口缺失或价格基准断裂在判定终局前记 `data_gap`。接口失败或预算耗尽不伪装成已结算，已发布结算不重写。
- `auto` 是无人值守前瞻入口：自动定位最近已收盘交易日（18:00 收盘边界），若账本尚未扫描则执行 `scan`；若总预算仍有剩余（>=1），继续执行到期样本 `settle`；最终调用 `report` 将不可变报告原子保存至 `--report-dir/<cutoff>.json`。全部步骤共享同一次请求硬预算（例如 100 次），前一步未用完的预算才结转给后一步。报告目录须与账本根目录物理分离。
- `report` 同股间隔不足10个交易日只计第一次观察；主统计使用全部去重观察的扫描日收盘收益，不能只挑触发组。输出总观察数、已结算数、有效收益数、分月样本数和均值、20日超额均值与月聚类区间、正超额月份占比、MAE与基线中位数。前瞻月数取首次至最近前瞻扫描之间的完整日历月数，缺失或未到期样本不算有效收益，历史回填不计入上述统计。
- 新账本首行的 `contract.promotion` 冻结晋升条件版本与全部统计参数。默认 `simple-promotion-v2`：至少3个完整日历月、150个有效已结算去重观察、2个有效收益月份；只判定**观察等权20日超额月聚类90%双侧正态近似区间（z=1.645）下沿>0**。显式完整冻结的 `simple-promotion-v1` 也受支持，固定为6个月、300个有效观察、至少2个月聚类、95%双侧区间（z=1.96），其余统计与单一下沿门槛相同。报告只按首行选择合同，未来默认版本或参数变化不改变已支持版本的含义；矛盾、缺失参数或未知版本明确拒绝报告。
- 数据不足为 `insufficient`，充分时为 `pass/fail`；正月份比例、MAE和基线中位数仅作信息输出。权威晋升区间为 `excess20_ci`，其置信水平、双侧口径、方法与z值见 `promotion_contract`；兼容字段 `excess20_ci95` 始终另算真正的95%双侧月聚类诊断区间，不一定是晋升区间。无有效数据或不足2个月聚类时区间为 `null`。
- 未冻结晋升版本的既有账本无法推断原合同，不按时间或规则哈希猜测为6个月/300个，也不按当前默认重新判定。其报告保留计数、均值、MAE和95%诊断区间，但固定 `status=insufficient`、`status_reason=legacy_unfrozen_promotion_contract`，`promotion_contract` 与权威 `excess20_ci` 为 `null`。报告不迁移或改写账本；旧账本仍按已冻结观察条件结算。规则哈希或合同与当前默认不同（含旧未冻结账本）时，扫描在请求前提示“规则已变化须新账本”。不增加迁移或覆盖入口，不按已看到的结果调参；验证通过只支持另行讨论，不自动进入首页。

新账本另冻结 `contract.eligibility` 的 `before-next-session-v1` 时间资格合同。旧账本未冻结该合同仍可读取、结算并保留诊断统计，但报告为 `insufficient / legacy_unverified_forward_eligibility`，`eligibility_contract` 与权威晋升区间为 `null`，不自动把旧 `prospective` 标志升级为已验证资格；若同时未冻结晋升合同，优先保留原 `legacy_unfrozen_promotion_contract` 原因。旧账本不改写，新扫描须使用新账本。

## 缓存、账本完整性与统计实现

`FORWARD_CONTRACT` 只决定新账本默认合同；读取从首行选择固定版本，不引用可变默认。各版本精确冻结前瞻已结算去重观察总体、观察收盘入口、观察等权20日超额均值、月聚类正态近似方法及区间下沿>0的门槛，参数类型错误也拒绝报告。时间资格事件保存 `started_at`、`recorded_at`、`next_session` 与 `prospective_deadline`。无迁移或覆盖 CLI，不依据结果调参。

`replay.py` 的 `scan/settle/auto/report` 与历史 `fetch/run` 共用私有目录校验、互斥锁、请求硬预算、每次请求前0.5秒间隔和带哈希的原子JSON缓存。前瞻目录使用独立mode标记，拒绝与历史重放或研究目录混用；缓存按日期/范围命名，包含endpoint、params和fetched_at，读取校验哈希与请求身份。日历覆盖完整自然日，扫描验证最近61个交易日，证券列表按扫描日期冻结；每日全市场行情允许相邻扫描与后续结算复用。失败尝试计入硬预算，每项最多三次；预算耗尽不会追加不完整扫描/结算，保留缓存供另一次显式授权使用。

`ledger/events.jsonl` 第一行冻结规则身份、`price_conditions()`源码与引用常量的SHA-256，以及排序、基线种子、5日窗口、10日去重和收益期限；新账本还在 `contract.promotion` 冻结晋升条件版本与统计参数。之后仅追加scan或settle事件；每行含事件、自身哈希和上一行哈希。持有根目录锁时，用原有字节前缀加新行进行原子替换及文件/目录fsync，不重写已有事件内容。所有入口在请求或统计前校验整条链，拒绝缺失、损坏、重复扫描/结算和无对应扫描的结算。根标记额外保存链末哈希，检测整行尾部截断；链文件与末端锚点分别原子发布，若两次发布间中断则拒绝后续运行，不自动修复或报告成功。哈希不能抵御有目录写权限者同时重写整条链和锚点，不是外部真实性证明。

report完全离线，晋升要求已冻结且经核验的下一交易时段之前完成的前瞻资格；按扫描日排序、同股距上次保留观察至少10个交易日去重，未到期和缺失记录保留在总数但不填零。20日超额均值按有效观察等权；以观察月份为聚类单位，令N为有效观察数、G为有效月份数、μ为总体均值，标准误为 `sqrt(G/(G-1) × Σ月[Σ月内(x-μ)]²) / N`，区间为 `μ ± z × SE`。正月份比例按月内均值是否大于零计算，MAE比较观察与随机基线各自有效值的中位数。完整前瞻月数按首次至最近前瞻扫描的日历跨度计算（末日未到首次日号时扣除一个月）；历史补扫不参与跨度、去重、样本、区间或基线统计。
