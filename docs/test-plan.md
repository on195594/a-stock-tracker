## Affected Modules
- `scorer.py` — breakpoints interpolation, data_quality check, error paths
- `pipeline.py` — init, daily, outcome-update, accuracy-report commands
- `lib/cache.py` — predictions table, index_prices table (new tables)

## Key Interactions to Verify

### scorer.py
- Breakpoints linear interpolation produces correct values between anchor points
- Boundary: metric at exactly a breakpoint value
- Boundary: metric below min breakpoint → min score (no negative scores)
- Boundary: metric above max breakpoint → max score (no over-scoring)
- Invert field (pe_percentile_10y): lower % → higher score
- None fields → score=0, recorded in missing_fields, data_quality reduced
- data_quality = available non-fixed fields / 5 (non-fixed total)

### pipeline.py daily
- After batch fetch, INSERT OR IGNORE is truly idempotent (re-run = no duplicate rows)
- weights_hash computed from `frameworks` subtree only (not updated_at or version fields)
- price_at_score extracted from spot_em snapshot `最新价` field by stock code
- report_period extracted from cache JSON `report_period` field

### pipeline.py outcome-update
- outcome_30d = `(outcome_price / price_at_score - 1) * 100` (percentage, not absolute)
- estimate_flag=1 when using nearest available price (within 5 trading days)
- estimate_flag stays 1 on re-run (idempotent: CASE WHEN ? = 1 THEN 1 ELSE estimate_flag)
- outcome NULL when no trading data within 5 days of target date
- benchmark_30d failure → outcome written normally, benchmark_30d left NULL
- benchmark requires both score_date and target_date prices; one missing → NULL
- 60d/90d outcomes not overwritten if not yet due

### pipeline.py accuracy-report
- Output order: strong → moderate → light → no-action
- No division-by-zero when count=0 for a tier
- stat warning displayed when total closed records < 100
- exclusion count printed in header (NULL outcome rows excluded)

## Edge Cases
- Same-day weights.json change: pipeline.py daily detects hash conflict, warns and exits
- `pipeline.py init` on already-populated DB: fetcher handles TTL, no duplicate entries
- Watchlist stock with pe_percentile_10y=None (< 1 year listed): dimension scores 0, data_quality decremented
- All 5 non-fixed fields None: data_quality=0 → InsufficientDataError

## Critical Paths
- First-run: `pipeline.py init` → `pipeline.py daily` → verify predictions table populated
- Day 31: `pipeline.py outcome-update` → verify outcome_30d filled for day-1 predictions
- Weights edit: modify weights.json, re-run daily → verify conflict check fires before writing
