# 波段机会助手：模块与数据合同

目标与操作命令见 [README](../README.md)；开发和安全约束见 [AGENTS.md](../AGENTS.md)。本页只维护模块归属、兼容合同与历史边界。

```text
显式小池 + 日历/完整日线 → 确定性量价条件 → AI解释 + 复核 → 独立私有批次
                                                           ↓
                                          默认机会首页 / 条件详情（只读）

兼容研究入口：
config/anchors.json → 同业发现 → 我的研究 ← 指定公司代码
交易日历 → 提交时冻结目标日/范围 → 独立 worker → 不可变事实 JSON
                                                ↓
                                      私人 SQLite → 变化 / 已阅
全市场自动研究 → 独立私有 root → 机器报告（不进入个人工作区）
```

## 模块归属

| 模块 | 唯一职责 |
|---|---|
| `config.py` / `paths.py` | 参照 JSON 与目录；参照不等于个人关注 |
| `calendar.py` | 日历来源、完整性/覆盖验证、原子发布、最近已证明交易日 |
| `research.py` | 同业枚举、年度 ROE 选择、PB/ROE 平均名次与事实采集 |
| `watch.py` / `evidence.py` | 固定公司更新；财报选择、校验、展示与日期倒退判断 |
| `workspace.py` | 三表、模式、导入、持久化安全及共用快照读取/哈希校验 |
| `services.py` | 鉴权后的查询/写入、事实比较、任务受理；转换工作区错误供页面使用 |
| `worker.py` | 串行执行、任务身份验证、原子发布与崩溃恢复 |
| `app.py` / `auth.py` | Flet 页面、会话、OAuth 与 ASGI 边界 |
| `maintenance.py` / `manage.py` | 初始化、合成 demo、导入、一致备份与全新目录恢复 |
| `opportunities.py` | 有界波段采集、确定性价格条件、AI解释/复核、不可变批次与鉴权读取 |
| `opportunity_view.py` / `opportunity_demo.py` | 只读机会列表/详情；仅 loopback demo 与离线测试使用的合成示例 |
| `automation.py` | 旧全市场冻结、覆盖/行业排名、独立文件锁、预算和恢复 |
| `disclosures.py` / `scripts/automation_model.py` | 正式原文/逐页证据、无工具生成、逐字校验与独立语义复核 |

一个 Web、一个串行 worker；日历是独立维护命令，自动研究是另行授权的批处理。研究链不读取旧 tracker.db、财报观测库或旧 Python 配置，不用旧缓存冒充本次核查。

## 波段机会合同

主路由 `/` 与 `/opportunity/代码` 不打开个人数据库、不请求行情/模型，不复用 PB/ROE 名次作为推荐依据。旧流程移至 `/research`，旧发现/公司/任务链接保留。机会页回调沿用 actor、页面 generation 和 connected 检查，异步读取结果不得在切页、退出或断线后覆盖当前页面。

`swing-observation-v1` 的参数、工程阈值、价格公式和局限只在 [README](../README.md#波段观察批处理) 维护。先验证证券身份、日历覆盖、61个完整交易日和未复权价格连续性，再由程序产生事实与条件；缺口不交给模型补全。模型仅返回三个解释段及事实引用，数值由程序展示；另一模型调用复核事实支持，不通过不发布观察条件。

单批次最多5家公司，各自为 excluded / observation / gap；允许零观察。个股采集中的 `ScreenError`（如不支持的身份或行情资料缺口）保留为该股 gap，其他公司继续；共用日历/基准错误或采集阶段预算耗尽则不发布新指针。模型生成/复核失败或该阶段预算不足记为该股 gap，不保留可行动条件。采集完成后才创建 `swing-*` 目录，保存输入证据、模型请求/响应及结果，原子发布结果后才切换带哈希的 `latest.json`。发布成功前不把候选标为可读。旧批次不改写；没有批次续跑或跨批次缓存，不承诺失败无费用。

Web 只读 `OPPORTUNITY_ROOT`，读取前后检查 actor，限制文件大小、拒绝路径穿越/符号链接、验证校验和、规则身份和行状态；复核未通过不能展示为观察。校验和只用于完整性检查，不防止有目录写权限的人同时改写结果和指针。过期内容标作历史，主区域及展开依据均隐藏触发/失效条件与距离，原始批次和其余依据保留。观察有效期不等于持有期；首版不监控后续价格，不宣称条件已触发或仍未失效。认证/Host/Origin/upload 边界不变。

## 兼容研究：事实与排序

- peer-screen-v1 的资格、公式、并列及前三见 [规则合同](specs/2026-09-22-peer-screen-spec.md)。行业标签不证明业务可比；失败/partial 与上次完整榜分开，不用部分结果生成新的正式前三。
- 财务要求连续三份年报、证券身份、公告日期与修订选择；重复、截断、非有限值及冲突必须显式处理。发现扫描可按资格跳过请求；固定关注更新逐家公司重新核查，不受旧候选资格限制。
- 单公司/关注更新复用一次 `fina_indicator`，附带营收、归母/扣非归母同比、资产负债率及每股经营现金流。可选扩展 `research_report` 仅选择本次取得且已公告的最新报告期，唯一修订标记优先；缺口或版本冲突不回退、不跨快照拼接。
- 完整/部分财报均验证结构、来源与日期；公告不得晚于取得日（上海日期），异常指标不展示。旧快照无扩展仍可读并提示；新报告缺口阻止已阅。年度 ROE 提示按报告期排序。
- 兼容首页 `/research` 突出异常、风险状态与财报变化；PB、日期及来源范围变化折叠，不计入待处理数；仅核查时间变化不算财务变化。公司页先展示已保存判断摘要，再默认展开财报与原文入口、展示研究记录，最后确认事实已阅；已关注公司的记录表单默认展开，仍可收起且不强制填写。更新失败时最新财报区显示本次失败，旧资料只作历史参考。

## 兼容研究：状态与并发

- 三张业务表 `screen_runs`、`watch_items`、`update_jobs` 与历史 `source=tracker` / 规则身份保持兼容，不重算历史结果。这是个人研究工作区，不是旧行情库。
- 关注无需笔记；保存笔记不推进已阅，也不重新开启已经确认的已阅按钮。保存冻结点击时的表单并阻止重复提交；等待期间的新输入保留为未保存草稿，离开仍须确认。笔记和已阅校验 revision/updated_at，拒绝未关注、损坏、缺口、日期倒退、较新失败、过期版本及撤销授权。经过验证的 partial 中可用的单家公司事实可展示，但不能绕过逐公司已阅校验。
- 提交冻结目标日与范围，同 ID 不同意图拒绝，同范围在途合并。单公司沿用 `kind=watch`，意图为 `{"kind":"watch","code":"600900.SH"}` 且范围恰为该代码；批量为 `{"kind":"watch"}`。提交及 worker 均核验证券范围，生产指定公司须正常上市、沪深主板、非金融。暂停阻止批量更新，不阻止本人明确更新一家。
- worker 在网络请求前释放数据库事务；任务锁、防重放及恢复不可省略。快照固定路径、不可覆盖，哈希与任务身份一致、文件及各级父目录同步成功后才登记；恢复也必须重验，不以文件存在冒充成功。
- 关页面不取消任务。页面只读轮询，完成后由本人点击结果入口；切页、退出、撤权、断线后的迟到结果受会话/页面版本校验，不自动跳页或覆盖输入。

## 原财报自动研究隔离

自动研究的参数、预算、证据边界与退出语义只在 [README](../README.md#自动选股与机器研究独立批处理) 维护。它复用枚举、年度选择、平均名次及原子文件发布，不打开业务 SQLite、不把模型任务塞进 `update_jobs`。

每个证券恰有一个覆盖状态；证券身份一致且已证明非沪深主板时先排除，不因无关的行业/名称缺失阻断主板覆盖。主板缺行业/名称、上市/交易所/市场缺失及身份冲突仍是 gap。未完成组不发布排名，抽样永远 partial。报告先发布/校验，再提交终态和游标；游标表示已处理，不表示复核成功。首次 owner marker 失败后，只允许仅含普通 `.lock` 的私有 root 重试，持锁后复查目录；其他残留和非普通锁仍拒绝。
