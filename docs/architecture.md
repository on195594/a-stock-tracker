# 个股研究助手：模块与数据合同

产品目标、首版范围与验收见 [README](../README.md#产品目标与规格归属)；开发和安全约束见 [AGENTS.md](../AGENTS.md)。本页只维护模块归属、数据/发布合同、只读边界与历史隔离，不另立产品路线。

```text
网页选择目标 → 确认范围/预算/模型 → 独立研究接收器 → 一次性有界批处理
                                         ↓
                               /analysis/请求编号 → 结果/详情

显式小池 + 日历/完整日线 → 程序价格参考（无模型）→ 独立私有批次
研究 API info/recent/status → 首页进行中 / 最近研究链
单独配置 OPPORTUNITY_ROOT → 首页已发布批次区块 / 条件详情（OAuth）

market-research-v1 → 独立私有 root → 财报机器报告 → 结构化摘要/段落/引用
```

财报研究是主流程，初筛提供完整同业排名；每行财报动作预填代码与来源编号，仍需成本确认。价格纪律参考为独立确定性计算，不调用模型，不以趋势、相对强弱或 8% 距离排除资料完整的公司。量价结果保存在请求私有批次，不自动写入 `OPPORTUNITY_ROOT`；首页最近摘要通过接收器每次校验读取，过期隐藏价格。五个交易日是参考有效期，不是持有期。

## 页面与安全边界

OwnerAuthorization 使用 Flet 支持的授权扩展，在成功完成令牌交换与用户读取后记录一次性身份证明；创建 actor 时消费该证明，缓存 user、重复回调、失败交换或凭据恢复均不续期。OAuth state 仍由 Flet 校验；撤权、到期和关闭同时清除页面认证上下文，新授权必须重新完成 OAuth。

页面包括 `/`、`/opportunity/代码`、`/analysis`、`/analysis/<请求编号>`、`/analysis/<请求编号>/<代码>`、`/settings` 和登录/OAuth 流程。旧 `/research`、`/discover`、`/company/*`、`/jobs/*` 的 HTTP 请求返回 404，不重定向为旧页面；会话中的未知页面仅提供返回研究首页。

研究页回调检查 actor、页面 generation 和 connected，异步读取不得在切页、退出、断线或撤销/到期后泄露或覆盖内容。读取失败只提供重读与返回研究首页，不引导到旧工作台。保留 OAuth state、数字 ID 白名单、actor 到期/撤销、Host/WS Origin 与 `/upload` 限制；demo 仅 loopback 与合成数据，生产缺配置拒绝启动。

公开 JS/WASM 按客户端能力 gzip 压缩，范围请求保持原样，保留静态资源 ETag 条件读取。不压缩私人页面、OAuth 或研究响应，不增加业务缓存；同源裁剪中文字体不压缩，但配置 30 天长期静态缓存与 HTML 首屏预加载头，其余动态/业务资源不设长期缓存。动态压缩消耗 CPU，局域网与受限网络的耗时须分别测量。

## 网页研究请求合同

网页 `/analysis` 输入与确认，`/analysis/<32位随机编号>` 显示进度/结果，追加 `/<代码>` 查看该请求的量价详情。每次读取、操作和轮询都受 actor/generation/connection 检查；切页、退出、断线或撤权后的迟到回复不得覆盖当前界面。未确认不提交；受理未知时保留原请求编号和原始范围，核对同一请求而不静默新开收费。会话级待决状态保存不可变请求内容，切页及重连先恢复原编号核对，身份撤销时清除；迟到响应不能覆盖新路由。仅财报模型研究报价含 `model_budget`：调用最多 10 次、本地超时 240 秒、输出 token/费用硬上限为空，且超时不保证停止计费。页面须显式确认该边界，服务端精确核对并持久化；不含该边界的旧报价不能创建新执行，已受理编号仍幂等返回既有状态。量价报价的 model 为空，不含 model_budget，无需模型运行时；旧量价报价被拒绝时走同一 quote_changed 流程。预算或模型报价变化时服务端拒绝旧报价；返回 HTTP 409 和 `code=quote_changed`；客户端区分明确拒绝与受理未知，原页保留输入、重新获取报价并清除确认勾选。其他错误也返回机器可读 code。

接收器只通过私有 Unix socket（默认开发 loopback）接受强令牌认证请求，拒绝任意路径、CLI 参数、重复证券、额外键和超预算报价。目录有独立所有者标记，拒绝接入历史或混用批处理目录。短元数据锁串行落盘；独立执行锁一次只允许一项，传给预算子进程，再由受限命令启动器显式传给支持的直接模型/PDF进程；仅继承经设备号/inode校验的一枚租约描述符，外部命令环境移除传播标记。接收器和批处理主进程先后退出时，直接执行子进程存活期间仍持锁；任意外部运行时自行脱离的后代仍由 systemd 整个 cgroup 清理，不声称描述符机制覆盖无限后代。无自动队列/调度/恢复。子进程有现有时限；外层无论主进程正常或异常退出，都清理其进程组再释放锁。同日同预算且同门槛的普通财报初筛在复验原批次完整性后建立结果引用，不重复采集；引用目标为初筛链的末端最新结果；同编号轻量引用保持幂等，使用本次请求时间，原证据日期保持可见。状态返回 `continued_by`，已有后续请求的检查点不再允许续跑。部分覆盖且尚有待扫描股票时，网页提供显式继续入口，确认请求携带 `resume_from` 和本次新增预算。接收器只接受七天内、无模型调用且冻结门槛与当前报价一致的全市场初筛检查点，校验哈希、身份与路径后复制冻结范围、状态和已采集财报到新请求私有目录，再运行 `--resume --pb-mv-screen --max-research 0`。不改写原批次、不自动扩大预算、不重新采集已覆盖股票或重试 gap。一个检查点只接受一个后续请求，别名归一到原批次以防重复收费；重复编号继续保持幂等。每次读取仍复验被引用的批次。

模型调用先落盘请求和用量审计，再派发；失败或中断的未知用量不记为零，无合格响应的已发起调用不自动再次执行。pi 固定 SSE 和零传输重试，避免 WebSocket 失败后重新发送。运行时参数 `maxTokens=6000` 不等于服务端硬上限：当前 pi openai-codex 不下传它。子进程输出读取、单文件大小、研究目录预算及宿主 cgroup 的不同边界见 README；目录巡检并非硬磁盘配额。

请求与结果用现有原子落盘/哈希封装；文件或目录同步失败不能确认发布成功。完成后每次读取重新验证原始产物，量价结果重算到期标记；失败、中断或校验错误不展示旧成功结果。日志、模型原文和根路径不进入 Web 响应。网页仅展示十条近期研究链，不删除任何历史文件；续跑与复用合并到初筛链并标注次数。遍历只保留精简链元数据，再使用 top-10 校验读取状态与原始结果，投影为不含全文的摘要（状态、资料日期、反证首句或价格参考），不持久化摘要；新请求状态仅存元数据，不重复保存可从原始产物核验的结果，旧记录只读兼容、不迁移改写。原始结果的读取核验在请求元数据锁外进行；磁盘操作和锁等待由受限线程池执行，不阻塞服务事件循环。网页并行读取入口配置与历史；轮询数据未变时不推送页面，但每轮仍检查权限与连接，状态变化照常更新。

网页新初筛固定报价 1500 次数据请求 / 3600 秒；续跑为 `min(剩余待覆盖数 + 20, 1500)` 次，秒数按 `ceil(请求数 × 3600 / 1500)`（至少 66 秒，兼容采集器每家 65 秒的预留），含 0.5 秒间隔和同比例耗时余量。服务端基于已校验检查点比对报价，子进程与外层时限均使用已确认值。automation 的 invocation/state 记录实际请求数、耗时、停止原因和本轮/累计/剩余覆盖；旧批次未记录字段不推算成零。

初筛 API 返回完整行业 `groups`（比较年度和组内 PB/ROE 平均名次）；批处理 `candidates()[:5]` 仅控制研究队列。接近 4 MB 响应上限时截断排名并显式返回标记和说明。来源 `from` 仅为展示元数据，必须为本根目录内初筛请求的 32 位 hex 编号，不影响资格或预算。页面时间转为上海时间至分钟，不改原证据；执行、覆盖、结果分别展示，编号与来源放在“依据”中。

## 价格纪律参考合同

`price-reference-v1` 的公式与范围见 [README](../README.md#价格纪律参考批处理维护与高级使用)。先验证证券身份、日历覆盖、完整日线与未复权价格连续性，再复用冻结的 `price_conditions()` 计算。新输出只有 reference / gap；趋势、相对强弱和距离仅为事实，不用于排除。展示收盘、MA20/MA60、向上排列、20日相对涨幅差、观察线、失效线、收盘到失效线距离、依据日期与后续5个交易日有效期；不展示旧区间上沿或量能条件。

每批最多5家公司；单股采集 `ScreenError` 记为 gap，其余公司继续。共用日历/基准错误或采集预算耗尽不发布新指针。无模型调用、隐式重试或恢复。采集后创建 `swing-*` 目录保存证据与结果，先原子落盘结果再切换带哈希的 `latest.json`，文件及目录同步失败不能报告成功。

读取同时接受 `swing-observation-v1` 和 `price-reference-v1`，按规则校验行状态。旧规则仍核验原解释与复核、标明“旧规则批次”，过期隐藏原条件，不改写文件。`RULE`、`price_conditions()` 继续冻结供离线重放与后续验证使用。

Web 只读 `OPPORTUNITY_ROOT`，检查 actor、大小、路径/符号链接、校验和、规则与日期。过期隐藏观察线、失效线和距离，历史非行动事实保留；首页过期摘要隐藏价格。已渲染完成的研究详情、近期摘要及发布批次使用有限本地到期定时器，在上海时间有效期结束后重绘并隐藏可行动价位和距离，不为完成任务持续轮询；导航、断线与撤权取消旧定时器。完整性哈希不防止目录写入者同时篡改结果与指针，不代表来源真实性保证。

## 离线前瞻账本合同

`replay.py` 的 `scan/settle/report` 与历史 `fetch/run` 共用私有目录校验、互斥锁、请求硬预算、每次请求前0.5秒间隔和带哈希的原子JSON缓存。前瞻目录使用独立mode标记，拒绝与历史重放或研究目录混用；缓存按日期/范围命名，包含endpoint、params和fetched_at，读取校验哈希与请求身份。日历覆盖完整自然日，扫描验证最近61个交易日，证券列表按扫描日期冻结；每日全市场行情允许相邻扫描与后续结算复用。失败尝试计入硬预算，每项最多三次；预算耗尽不会追加不完整扫描/结算，保留缓存供另一次显式授权使用。

`ledger/events.jsonl` 第一行冻结规则身份、`price_conditions()`源码与引用常量的SHA-256，以及排序、基线种子、5日窗口、10日去重和收益期限；新账本还在 `contract.promotion` 冻结晋升条件版本与统计参数。之后仅追加scan或settle事件；每行含事件、自身哈希和上一行哈希。持有根目录锁时，用原有字节前缀加新行进行原子替换及文件/目录fsync，不重写已有事件内容。所有入口在请求或统计前校验整条链，拒绝缺失、损坏、重复扫描/结算和无对应扫描的结算。根标记额外保存链末哈希，检测整行尾部截断；链文件与末端锚点分别原子发布，若两次发布间中断则拒绝后续运行，不自动修复或报告成功。哈希不能抵御有目录写权限者同时重写整条链和锚点，不是外部真实性证明。

scan在上海时间18:00口径下只接受已收盘交易日，同一as_of不得重复；规则源码、引用常量或冻结统计合同变化时拒绝追加扫描并提示“规则已变化须新账本”。观察与随机基线均保存代码、名称、程序计算条件、61日交易日历、记录时间与请求数；非观察但资料有效的股日也参与最多500只的随机基线。时间资格由独立冻结的 `contract.eligibility`（`before-next-session-v1`）约束：日历请求覆盖 as_of 后 32 个自然日，验证下一实际交易日；扫描完成时间必须早于该日上海时间 09:15。18:00 仅控制资料可用性。事件保留 `started_at`、完成时刻 `recorded_at`、`next_session`、`prospective_deadline`；延迟或跨开盘完成扫描只作历史记录，报告不计入晋升。所有输出按代码排序，不引入跨股票评分或择时排名。

settle只在扫描日之后65个交易日均已收盘时运行，逐扫描日追加结果，保存结算日历及时间。5日窗口按低价先失效、收盘及量能满足触发、收盘越过上沿、最终过期的顺序判断；尚未判定终局前缺日/无效价格或价格基准断裂记data_gap。扫描日收盘收益用于晋升，触发日收益另列，不能用触发样本替代全部观察。收益与基准均逐日乘close/pre_close，不补齐缺失；10/20/40/60日各期限只在截至该期限的整条链有效时给出结果。低价、开盘价按同一链调整后用于20日MAE及止损模拟。空数据、无效价格、停牌零量记缺口，后续收益为null；来源冲突、接口失败或预算耗尽拒绝发布该结算，不伪装为零收益。已结算记录为终态，不自动重试或改写；代码规则变化后仍能使用已冻结条件结算和报告。

report完全离线，晋升要求已冻结且经核验的下一交易时段之前完成的前瞻资格；按扫描日排序、同股距上次保留观察至少10个交易日去重，未到期和缺失记录保留在总数但不填零。20日超额均值按有效观察等权；以观察月份为聚类单位，令N为有效观察数、G为有效月份数、μ为总体均值，标准误为 `sqrt(G/(G-1) × Σ月[Σ月内(x-μ)]²) / N`，区间为 `μ ± z × SE`。正月份比例按月内均值是否大于零计算，MAE比较观察与随机基线各自有效值的中位数。完整前瞻月数按首次至最近前瞻扫描的日历跨度计算（末日未到首次日号时扣除一个月）；历史补扫不参与跨度、去重、样本、区间或基线统计。

`FORWARD_CONTRACT` 只决定新账本默认合同；报告从首行合同选择固定版本，不引用可变默认。`simple-promotion-v2` 冻结至少3个完整日历月、150个有效已结算去重观察、2个有效月聚类、90%双侧置信水平及正态近似z=1.645；显式冻结的旧简单合同 `simple-promotion-v1` 固定为6个月、300个有效观察、2个有效月聚类、95%双侧及z=1.96。两版均冻结前瞻已结算去重观察总体、观察收盘入口、观察等权20日超额均值、月聚类正态近似方法和区间下沿>0的单一门槛。固定版本定义与当前默认分离，首行全部参数须与该版本精确匹配，类型错误、参数缺失/矛盾或未知版本拒绝报告。数据充分才输出pass/fail，否则为insufficient；其他指标只作信息输出。

权威区间 `excess20_ci` 的元数据（confidence、two_sided、method、z）与充分性阈值随选中的 `promotion_contract` 返回，limits同时标明该口径。兼容字段 `excess20_ci95` 独立使用z=1.96计算95%双侧月聚类诊断区间，不一定用于晋升；无有效数据或不足2个月聚类时区间为null。未冻结晋升版本的既有首行合同只作legacy读取，不能依据时间或规则哈希推断为任一版本：保留信息统计与95%诊断区间，固定 `status=insufficient`、`status_reason=legacy_unfrozen_promotion_contract`，`promotion_contract` 与 `excess20_ci` 为null，不声称已知冻结置信水平。report不改写事件、首行、哈希或末端锚点；旧账本仍可用冻结条件settle，但legacy或不同当前合同的scan在请求前拒绝。无迁移或覆盖CLI；禁止根据已看到的结果调参，解释见[README](../README.md#离线重放验证)。

未冻结时间资格的旧账本仍按原证据结算、提供信息统计，`eligibility_contract=null`、权威区间为null，固定 `insufficient / legacy_unverified_forward_eligibility`；同时缺晋升合同的账本优先保留原缺晋升合同原因。禁止依据旧 prospective 标志自动补合同或重写账本。历史 fetch/run 输出单列 `historical-replay-v2` 方法版本：按观察入场后的完整收益链计算，任何中间缺口不补零，入场前异常不污染后续窗口；五日结果共用缺口及价格基准连续性校验。

前瞻账本与缓存不挂载给Web，不进入研究服务或首页；不增加调度、通知、模型和交易调用。逐次授权、离线结果不证明收益、保留B验证线但不在价值池自动叠加择时的决策与历史重放依据统一维护在README，不保留另一份阶段方案。

## 独立财报研究

`market-research-v1` 的预算与退出语义见 [README](../README.md#自动选股与机器研究独立批处理)。它不依赖旧业务数据库，也不把财报排名转换为投资建议。共用范围资格、年度选择与平均名次见 [peer-screen-v1](specs/2026-09-22-peer-screen-spec.md)；证券覆盖、原文引用、私有目录锁和恢复检查继续维护。批处理从当次行情日历确定并冻结估值日，不回退到本地日历维护文件。网页初筛由接收器固定传入 `--pb-mv-screen --max-research 0`，前置门槛见财报子规格。门槛进入报价、冻结快照和结果；接收器将已确认门槛的摘要通过 `--screen-contract` 传给子进程，子进程在连接行情前核对当前规则，拒绝服务未重启而磁盘规则已变化的请求。`total_mv` 保留原始万元单位；仅通过前置校验的行请求财报，缺失不填零。旧规则批次仍可读，但不自动续跑或复用为新结果；指定股票研究不应用此门槛。扫描先核验所有已保存记录，再按行业剩余待扫描数量升序推进，无已知缺口的行业优先；不改变冻结范围内的资格、排名公式或原冻结行顺序，也不保证在预算内出现候选。个人参照筛选、关注列表排名、本地日历自动选日及专用测试已移除；这些删除不改变批处理使用的证据校验与排序公式。

财报 API 从 `read_result` 已校验的原始 report JSON 组装结构化投影，不读取未校验 Markdown、不改写旧批次。返回 status、evidence_review、各文档 period/announced、行业/估值日/PB/ROE 线索、五段 analysis（text 与 fact id）、facts（id/claim/title/page/period/announced/quote/url）、scope_gaps + report gaps、omitted_pages 数量和失败 error。只放行 evidence_review=passed 的 analysis/facts，不返回 rejected_draft 或原始页全文。页面使用 Text 与 ExpansionTile，不渲染 Markdown、图片或外链；复核失败与原文/模型失败分别用中文说明。

## 部署与历史隔离

`docker-compose.research.yml` 为 Web 挂载整个桥目录（只读）及接收器令牌，因此宿主桥目录必须专用、只含 socket，不能与研究目录、模型运行时或凭据目录混用。启动检查验证路径无符号链接、目录私有及目标为 socket，拒绝其他目录内容，并拒绝桥目录与研究根目录相同或互为祖先。部署仍须核对实际挂载，运行后不能向桥目录写入私人文件。`.research.env` 属于宿主接收器，`.research-web.env` 只含桥配置；均 Git 忽略且 Docker 构建排除。宿主接收器配置/启动与 Web 覆盖部署须明确授权，不因改源码自动运行。`deploy.sh` 首次部署默认不启用；若现有 Web（含停止容器）包含研究环境项或桥挂载，省略开关会在修改前中止。`RESEARCH_WEB_ENABLED=1` 显式加载桥配置，`0` 显式停用 Web 桥，其他值拒绝；不因配置文件存在自动启用。启用后从新 Web 容器经私有 socket 认证读取 `GET /info`，不输出令牌/响应、不启动接收器或研究；失败中止 Nginx 切换，但不自动回滚已重建的 Web。

宿主持久接收器服务模板为 `config/a-stock-tracker-research.service`，定义用户级 systemd 单元与 cgroup 限制（`MemoryMax=1G`、`CPUQuota=100%`、`TasksMax=64`）；异常退出 10 秒后重启（5 分钟最多 3 次），手动停止不重启。服务仅重启接收器，不自动恢复、重试或新建研究批次；敏感凭据仅留于宿主私有 `.research.env`，不写入单元文件。

发布目录使用独立 `PUBLICATION_WEB_ENABLED=0/1`，省略且现有 Web 含 OPPORTUNITY_ROOT 或发布挂载时在修改前拒绝继续。启用时添加固定 opportunities 覆盖文件，两项显式开关可组合；`.env` 插值保留，研究环境在其后加载，导出变量优先。停用不删除宿主产物。

基础 compose 只有 Web，不挂载 `data/research` 或日历，不加载 `.worker.env`。可选覆盖文件将独立价格参考目录只读挂载；Web 启动无需旧工作区初始化。部署脚本在构建后用 `--remove-orphans` 移除旧 worker 容器，不带删除卷参数；该动作只在下一次明确授权部署时执行。源码删除不等于生产已停用，现存 cron/容器不在本次源码修改中更改。

历史私人数据库、笔记、快照、日志与备份原样留在宿主目录，不进 Git、镜像或静态资源。旧三表/schema、快照身份与数据不迁移或重算。旧工作台源码和维护方法在 `fb408f4` 保存，只能从 Git 历史查阅，不提供当前入口。
