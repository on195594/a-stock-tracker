# peer-screen-v1：同业发现规则

本文件只定义仍在使用的同业范围、资格、公式与快照语义。当前入口与运行方式见 [README](../../README.md)，工作区和关注更新合同见 [架构](../architecture.md)。规则沿用 2026-09-22 版本；原双仓 CLI、报告生成和分阶段交付说明由 Git 历史保存，不再作为操作入口。

## 参照与同业范围

参照来自本项目 `config/anchors.json`，必须是当前沪深主板非金融公司。行业不明、不在主板或属于金融行业时明确失败，不猜行业、不更换公式。金融排除使用 `research.py` 中的提供方行业关键词。

同次 `stock_basic` 按行业标签枚举当前沪深主板同业。先保留参照公司，其余按**同一估值日的有限正总市值降序**取至多 49 家，同值按证券代码。缺总市值的同业单列；截取后缺 PB、财务或不合格，不从截取范围外补位。参照缺资料仍保留事实与缺口，不伪造名次。

这是有市值偏向、最多 50 家的粗粒度比较，行业标签不保证主营业务可比。参照清单不限制池外同业参与，也不是界面中的个人关注。历史字段 `watchlist_codes` / `in_watchlist` 保留原语义，指参照清单成员。

基础枚举或同日估值为空、含重复证券或疑似接口截断时，扫描失败；个别公司缺资料则单列，不能把剩余结果冒充完整榜。

## 数据、日期与来源

| 输入 | 当前采集来源 | 用途 |
|---|---|---|
| 代码、名称、行业、市场、交易所、上市状态 | `tushare.stock_basic` | 确认范围和名称风险标记 |
| PB、总市值、所属交易日 | `tushare.daily_basic` | 同日比较与范围截取 |
| 年报 `roe_waa`、报告期、公告日、`update_flag` | `tushare.fina_indicator` | 三年逐项 ROE、版本选择与均值 |

只有用户提交任务后，worker 才发起研究取数。页面读取、保存笔记、已阅都不联网采集。发现扫描中，缺 PB 或已知 ST 警示可使财务请求跳过；PB 非正但有值时仍取财务。个人关注的固定范围更新不受这些筛选资格限制，每次重新核查财务。

提交时冻结上海今天之前、日历已证明的最近交易日；日历缺失或过期就拒绝新任务。PB 与总市值只接受目标日，不静默换日。日历刷新是独立维护命令。

这不是历史时点回测：`data_date` 是估值日，财务可用性按本次实际采集日判断，可能包含估值日之后披露的修订。来源、公告日期与取得时间分别保留，不能互相替代。

### 年报选择

- 使用最近披露的连续三个完整年度，每年一个可确认版本；不跳缺年、不用季度凑数。
- 财报期不能晚于估值日；公告不能早于财报期或晚于实际采集日。只有公告日期时保留日期精度。
- 接口出现完全重复记录、证券身份错配或疑似截断即报缺口。年度选择函数可折叠相同版本；有且仅有一条 `update_flag=1` 时采用修订记录，无修订且只有一条 `update_flag=0` 时采用原始记录，其他多版本冲突不参与排名。
- 最新年度期末距估值日超过 550 个自然日，不参与排序。550 天是运行限制，不是投资最优参数。
- 数值必须有限；布尔、NaN、无穷、空串和 null 不能充当正常值。ROE 用百分数，差值用百分点；PB 用倍数；市值只在同一来源单位下排序。

### 风险标记

同次基础信息的当前名称去首尾空白并转大写后，以 `ST` 或 `*ST` 开头即为已知名称风险警示，排除候选。名称缺失记为未知；其他风险未核验不意味着已解除。名称规则不覆盖全部风险警示、停牌和可交易性，仍须人工核查。

## 资格与排序

候选必须具备来源和日期合格的三份年报与同日 PB，**三年 ROE 均值 > 0、PB > 0**，且没有已知名称风险警示。某一年 ROE 为负但三年均值为正仍可参与，展示时提示负值事实。

```text
roe_mean = 三个年度 roe_waa 的简单平均
roe_rank = roe_mean 在共同合格同业中从高到低的平均名次
pb_rank = PB 在同一共同合格同业中从低到高的平均名次
research_order = (roe_rank + pb_rank) / 2
```

同值取平均名次；按 `research_order` 升序、证券代码升序确定最终位置，不使用展示舍入值计算。最多显示前三，参照不在前三时单列。少于三家显示实际数量，不宣称筛选胜出。合格参照参与排名，不合格参照只展示事实和原因。

排序只安排研究顺序，不是买入评分、低估结论或上涨概率。没有跨行业总榜、权重优化或收益验证。

## 展示、快照与已阅

展示采用年报、估值日、来源、覆盖和缺口，候选说明包含排名原因、与合格参照的指标差值、负 ROE/最新年度下降及人工核查问题。年度不同明确提示；参照不合格时不算差值。PB 中位数只在完整且同估值日、同财务年度的至少两家合格样本内比较。

快照保留全部截取成员，不能只存前三或均值：

| 字段 | 语义 |
|---|---|
| `schema_version`、`rule`、`limits`、`formula` | 格式、规则身份、50/3/550 限制与公式 |
| `screened_at`、`generated_at`、`data_date` | 本次观察时间、生成时间、估值日 |
| `anchor`、`watchlist_codes`、`scope` | 参照、冻结的参照清单、枚举/截取/排除成员及依据 |
| `rows` | 基础信息、PB、逐年 ROE、公告日、修订依据、来源、核查时间与缺口 |
| `results` | 合格集合、名次、前三与参照位置 |
| `workspace_meta` | worker 任务身份、冻结日期与意图摘要 |

`complete` 要求规则、事实、排名、范围通过验证，并有参照清单之外的合格公司参与；可解释的部分结果为 `partial`。未知规则、重放或无法核验的旧资料为 `unverified`，不得冒充当前完整榜。导入保留原始字节和历史结果，校验可重算排名作比对，但不改写原快照。

关注公司的事实对照使用“上次已阅 → 当前展示”的准确快照，不跨快照拼完整资料。数据缺失、范围变化不能写成经营恶化；PB 变化不能直接归因股价。保存笔记不推进已阅，缺口、损坏、日期倒退与较新的失败会阻止确认。固定关注更新不重新筛选或改写历史同业名次。
