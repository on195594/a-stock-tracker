# peer-screen-v1：独立财报研究子规格

**规格层级：这是独立财报研究的子规格，不是项目总 spec。产品目标、首版范围与验收以 [README](../../README.md#产品目标与规格归属) 为准。**

本文件定义独立 `market-research-v1` 批处理使用的范围资格、财报版本选择和排序公式，不定义波段推荐。`swing-observation-v1` 按自身的证券身份、完整日线和量价规则形成观察，不采用本文件的三年财报资格或排名。当前运行方式见 [README](../../README.md)，隔离边界见 [架构](../architecture.md)。

## 范围与分组

批处理使用同次 `stock_basic` 的证券代码、名称、市场、交易所、上市状态及行业标签确认范围。沪深主板上市非金融公司进入资料核验；范围外公司单列排除，身份冲突、行业或名称缺失记为缺口。金融排除使用 `a_stock_tracker/research.py` 中的提供方行业关键词，不猜行业、不更换公式。

全市场模式逐项记录冻结范围内公司的资格和资料状态，不按总市值截取同业。排序按行业标签及相同的三个年报期分组，不作跨行业比较；行业标签不保证主营业务可比。

基础枚举或同日估值为空、含重复证券或疑似接口截断时，扫描失败。行业存在资料缺口或待采集项时不发布该组排名；行业未知时不发布任何行业组。样本模式始终标记为局部结果，不能冒充完整市场扫描。

## 数据、日期与来源

| 输入 | 共用采集来源 | 用途 |
|---|---|---|
| 代码、名称、行业、市场、交易所、上市状态 | `tushare.stock_basic` | 确认范围和名称风险标记 |
| PB、所属交易日 | `tushare.daily_basic` | 同日估值与资格校验 |
| 年报 `roe_waa`、报告期、公告日、`update_flag` | `tushare.fina_indicator` | 三年逐项 ROE、版本选择与均值 |

独立批处理确定并冻结估值日，同日估值只接受目标日，不静默换日；已知 ST 或缺资料须记录，不伪造资格。日历仍是独立维护命令。

这不是历史时点回测：`data_date` 是估值日，财务可用性按本次实际采集日判断，可能包含估值日之后披露的修订。来源、公告日期与取得时间分别保留，不能互相替代。

### 年报选择

- 使用最近披露的连续三个完整年度，每年一个可确认版本；不跳缺年、不用季度凑数。
- 财报期不能晚于估值日；公告不能早于财报期或晚于实际采集日。只有公告日期时保留日期精度。
- 接口出现完全重复记录、证券身份错配或疑似截断即报缺口。年度选择函数可折叠相同版本；有且仅有一条 `update_flag=1` 时采用修订记录，无修订且只有一条 `update_flag=0` 时采用原始记录，其他多版本冲突不参与排名。
- 最新年度期末距估值日超过 550 个自然日，不参与排序。550 天是运行限制，不是投资最优参数。
- 数值必须有限；布尔、NaN、无穷、空串和 null 不能充当正常值。ROE 用百分数，差值用百分点；PB 用倍数。

### 风险标记

同次基础信息的当前名称去首尾空白并转大写后，以 `ST` 或 `*ST` 开头即为已知名称风险警示，排除候选。名称缺失记为未知；其他风险未核验不意味着已解除。名称规则不覆盖全部风险警示、停牌和可交易性，仍须人工核查。

## 资格与排序

候选必须具备来源和日期合格的三份年报与同日 PB，**三年 ROE 均值 > 0、PB > 0**，且没有已知名称风险警示。某一年 ROE 为负但三年均值为正仍可参与，展示时提示负值事实。

```text
roe_mean = 三个年度 roe_waa 的简单平均
roe_rank = roe_mean 在共同合格同业中从高到低的平均名次
pb_rank = PB 在同一共同合格同业中从低到高的平均名次
order = (roe_rank + pb_rank) / 2
```

同值取平均名次；按结果字段 `order` 升序、证券代码升序确定最终位置，不使用展示舍入值计算。每组最多列出前三作为研究顺序入口；少于三家列出实际数量，不宣称筛选胜出。

排序只安排财报研究顺序，不是买入评分、低估结论或上涨概率。没有跨行业总榜、权重优化或收益验证。该批处理的覆盖、排名或报告复核通过，不构成波段首版验收；不能直接将行业前三作为波段机会发布。
